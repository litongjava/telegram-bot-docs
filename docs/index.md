# Telegram Bot

使用 Java 和 tio-boot 开发 Telegram 机器人的文档。

| 章节 | 内容 | 建议 |
| --- | --- | --- |

| [第 3 章 tdlight](./tdlight/) | 使用 tio-boot 整合 tdlight | 需要 TDLib 能力时阅读 |
| [第 4 章 Telegram4J](./telegram4j/) | 基于 MTProto 的翻译机器人和错误处理 | **不推荐**：有并发问题，服务总是挂掉 |
