# 工具类参考

下表列出 telegram-bot-utils 和 telegram-bot-base 的公开静态方法。参数和重载以[源码](https://github.com/litongjava/telegram-bot-utils)为准。

## 客户端与限流

包名 `com.litongjava.telegram.can`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `TelegramClientCan` | 静态字段 `main`、`botId` | 保存全局 `TelegramClient`，启动时赋值后全局使用 |
| `TelegramClientCan` | `execute`、`executeAsync` | 发送请求 |
| `TelegramClientCan` | `deleteMessage`、`deleteMessageAsync`、`copyMessage`、`copyMessages` | 删除和复制消息 |
| `TelegramClientCan` | `getMe`、`getChat`、`getChatMember`、`leaveChat` | 查询机器人和会话信息，退出会话 |
| `RateLimiterManager` | `acquire`、`acquireOf100`、`getSemaphore30`、`shutdown` | 发送限流 |

## 接收消息

包名 `com.litongjava.telegram.utils`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `LongPollingMultiThreadUpdateConsumer` | `hasCommand`、`isPrivateChat` | 多线程处理长轮询更新，继承后实现业务逻辑 |
| `TgUserUtils` | `getUserId`、`getUsername` | 读取用户信息 |
| `TelegramBotUtils` | `getSelfId`、`getBotUrl`、`getBotStartUrl` | 读取机器人 ID 和链接 |
| `ChatType` | 常量，如 `chat_private` | 会话类型 |
| `TextFilerUtils` | `filterEmoji`、`truncateWithEllipsis` | 过滤表情、截断文本 |

## 发送消息

包名 `com.litongjava.telegram.utils`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `SendMessageUtils` | `text`、`html`、`markdown`、`markdownv2` | 构造 `SendMessage` |
| `TgSendUtils` | `sendText`、`sendHtml`、`sendMarkdown` | 发送文本 |
| `EditMessageUtils` | `text`、`html` | 编辑消息 |
| `SendPhotoUtils` | `file` | 发送图片 |
| `SendVideoUtils` | `file`、`url` | 发送视频 |
| `SendDocumentUtils` | `file` | 发送文件 |
| `TelegramMediaUtils` | `getMedias`、`getInputMedias`、`getInputMediasByUpdate` | 读取和转换媒体 |

## 键盘与回调

包名 `com.litongjava.telegram.utils`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `ReplyKeyboardUtils` | `build` | 构造回复键盘 |
| `InlineKeyboardMarkupUtils` | `create`、`createRow`、`createInlineKeyboard` | 构造内联键盘 |
| `InlineKeyboardButtonUtils` | `callback`、`url` | 构造内联按钮 |
| `AnswerCallbackUtils` | `alert` | 应答回调查询 |

## telegram-bot-base

| 类 | 包名 | 用途 |
| --- | --- | --- |
| `EchoCommandFunction`、`InfoCommandFunction` | `com.litongjava.telegram.bot.command` | `/echo`、`/info` 命令 |
