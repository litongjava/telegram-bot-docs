# 工具类参考

本页列出 telegram-bot-plus 的公开方法。参数和重载以[源码](https://github.com/litongjava/telegram-bot-plus)为准。

## 客户端与限流

包名 `io.nexus.telegram.can`。

| 类 | 成员 | 用途 |
| --- | --- | --- |
| `TelegramClientCan` | 静态字段 `main`、`botId` | 全局 `TelegramClient` 和机器人 ID，启动时赋值 |
| `TelegramClientCan` | `execute(...)`、`executeAsync(...)` | 带限流和重试的发送入口，详见[并发、限流与退出](./03.md) |
| `TelegramClientCan` | `deleteMessage`、`deleteMessageAsync`、`copyMessage`、`copyMessages` | 删除和复制消息 |
| `TelegramClientCan` | `getMe`、`getChat`、`getChatMember`、`leaveChat` | 查询机器人和聊天信息，退出聊天 |
| `RateLimiterManager` | `acquire`、`acquireAsync`、`acquireOf100`、`acquireOf100Async`、`shutdown` | 发送限流 |

`execute` 支持的请求类型：`SendMessage`、`SendDocument`、`SendVideo`、`SendPhoto`、`SendMediaGroup`、`GetMe`、`AnswerCallbackQuery`、`EditMessageText`、`CreateChatInviteLink`、`DeleteMessage`、`DeleteMessages`、`LeaveChat`、`PromoteChatMember`、`GetChat`、`CopyMessage`、`ForwardMessage`、`CopyMessages`、`GetChatMember`。

`executeAsync` 支持：`SendMessage`、`SendDocument`、`SendVideo`、`SendPhoto`、`SendMediaGroup`、`CopyMessage`、`DeleteMessage`、`CopyMessages`、`DeleteMessages`。

## 接收消息

包名 `io.nexus.telegram.utils`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `LongPollingMultiThreadUpdateConsumer` | 抽象方法 `consume(Update)`、`consumeGroup(List<Update>)` | 继承后实现业务逻辑 |
| `LongPollingMultiThreadUpdateConsumer` | `hasCommand(Message, String)`、`isPrivateChat(Message)` | 判断命令和私聊 |
| `TgUserUtils` | `getUserId(Update)`、`getUsername(Update)` | 读取发送者 |
| `TelegramBotUtils` | `getSelfId()`、`getBotUrl()`、`getBotStartUrl()` | 读取机器人 ID 和链接 |
| `ChatType` | 常量 `chat_private` | 聊天类型 |
| `TextFilerUtils` | `filterEmoji(String)`、`truncateWithEllipsis(String, int)` | 过滤表情、截断文本 |

## 发送消息

包名 `io.nexus.telegram.utils`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `SendMessageUtils` | `text`、`html`、`markdown`、`markdownv2` | 构造 `SendMessage` |
| `TgSendUtils` | `sendText`、`sendHtml`、`sendMarkdown` | 直接发送文本 |
| `EditMessageUtils` | `text`、`html` | 构造 `EditMessageText` |
| `SendPhotoUtils` | `file(channelId, fileId, fileTitle)` | 构造 `SendPhoto` |
| `SendVideoUtils` | `file(chatId, fileId, fileTitle)`、`url(chatId, title, videoUrl)` | 构造 `SendVideo` |
| `SendDocumentUtils` | `file(chatId, fileId, caption)` | 构造 `SendDocument` |
| `TelegramMediaUtils` | `getMedias`、`getInputMedias`、`getInputMediasByUpdate` | 读取和转换媒体 |

## 键盘与回调

包名 `io.nexus.telegram.utils`。

| 类 | 方法 | 用途 |
| --- | --- | --- |
| `ReplyKeyboardUtils` | `build(List<KeyboardRow>)` | 构造回复键盘 |
| `InlineKeyboardMarkupUtils` | `create`、`createRow`、`createInlineKeyboard` | 构造内联键盘 |
| `InlineKeyboardButtonUtils` | `callback(text, callbackData)`、`url(text, url)` | 构造内联按钮 |
| `AnswerCallbackUtils` | `alert(callbackQueryId, message)` | 应答回调查询 |

## 频道信息
