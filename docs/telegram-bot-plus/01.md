# 快速开始

本页写一个最小的回声机器人：收到文本后原样发回。先按[安装说明](./index.md#安装)安装 telegram-bot-plus，并向 [@BotFather](https://t.me/BotFather) 申请 Bot Token。

## 依赖

```xml
<properties>
  <maven.compiler.source>21</maven.compiler.source>
  <maven.compiler.target>21</maven.compiler.target>
</properties>

<dependencies>
  <dependency>
    <groupId>io.nexus</groupId>
    <artifactId>telegram-bot-plus-utils</artifactId>
    <version>1.0.0</version>
  </dependency>
</dependencies>
```

## 处理消息

继承 `LongPollingMultiThreadUpdateConsumer`，实现两个方法：

- `consume(Update)`：处理单条更新。
- `consumeGroup(List<Update>)`：处理媒体组（相册）。不需要时逐条转给 `consume`。

```java
import java.util.List;

import org.telegram.telegrambots.meta.api.objects.Update;
import org.telegram.telegrambots.meta.api.objects.message.Message;

import io.nexus.telegram.can.TelegramClientCan;
import io.nexus.telegram.utils.LongPollingMultiThreadUpdateConsumer;
import io.nexus.telegram.utils.SendMessageUtils;

public class EchoConsumer extends LongPollingMultiThreadUpdateConsumer {
  @Override
  public void consume(Update update) {
    if (!update.hasMessage() || !update.getMessage().hasText()) {
      return;
    }
    Message message = update.getMessage();
    if (hasCommand(message, "/start")) {
      TelegramClientCan.execute(SendMessageUtils.text(message.getChatId(), "发送任意文本，我会原样发回。"));
      return;
    }
    TelegramClientCan.execute(SendMessageUtils.text(message.getChatId(), message.getText()));
  }

  @Override
  public void consumeGroup(List<Update> updates) {
    updates.forEach(this::consume);
  }
}
```

`hasCommand` 同时匹配 `/start` 和群聊中的 `/start@your_bot`。

## 启动

发送前必须给 `TelegramClientCan.main` 赋值，否则会抛出 `IllegalStateException`。

```java
import org.telegram.telegrambots.client.okhttp.OkHttpTelegramClient;
import org.telegram.telegrambots.longpolling.TelegramBotsLongPollingApplication;

import io.nexus.telegram.can.RateLimiterManager;
import io.nexus.telegram.can.TelegramClientCan;

public class EchoBot {
  public static void main(String[] args) throws Exception {
    String token = System.getenv("TELEGRAM_BOT_TOKEN");
    TelegramClientCan.main = new OkHttpTelegramClient(token);
    EchoConsumer consumer = new EchoConsumer();

    TelegramBotsLongPollingApplication application = new TelegramBotsLongPollingApplication();
    application.registerBot(token, consumer);

    Runtime.getRuntime().addShutdownHook(new Thread(() -> {
      try {
        application.close();
      } catch (Exception e) {
        e.printStackTrace();
      }
      consumer.close();
      RateLimiterManager.shutdown();
    }));
    Thread.currentThread().join();
  }
}
```

同一个 Bot Token 同一时间只能运行一个长轮询实例。需要访问代理才能连接 Telegram 时，参考[翻译机器人的 HTTP 客户端](./02.md#http-客户端)。
