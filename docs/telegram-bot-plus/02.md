# 开发翻译机器人

::: warning 现阶段需要自行下载构建
telegram-bot-plus 还没有发布到 Maven Central，现阶段需要自行下载源码并构建安装，否则 Maven 找不到依赖。步骤见[安装](./index.md#安装)。
:::

[max-translator-bot](https://github.com/litongjava/max-translator-bot) 基于 telegram-bot-plus、tio-boot 和 java-openai 的 `UniChatClient` 开发：中文翻译为英文，英文翻译为中文，结果缓存在 PostgreSQL。本页的代码都取自该项目。

## 功能

- 支持 `/start`、`/help`、`/info` 和 `/echo <完整文本>`。
- 普通文本进入翻译服务，非文本消息被忽略。
- 超长回答分条发送。
- 相同翻译命中缓存，不重复调用模型。

## 运行

需要 Java 21 和 PostgreSQL，并先创建 `ai_translator` 数据库。

1. 安装 [telegram-bot-plus](./index.md#安装)。
2. 复制 `src/main/resources/app-dev.properties.example` 为 `app-dev.properties`，填写数据库地址和账号：

   ```properties
   jdbc.url=jdbc:postgresql://127.0.0.1:5432/ai_translator
   jdbc.user=postgres
   jdbc.showSql=false
   jdbc.MaximumPoolSize=2
   ```

3. 在启动目录创建 `secrects.txt`（项目沿用的文件名，已被 Git 忽略）：

   ```properties
   DEEPSEEK_API_KEY=your-api-key
   telegram.bot.token=your-bot-token
   jdbc.pswd=your-database-password
   ```

4. 构建并从项目根目录启动：

   ```bash
   mvn clean package -DskipTests -Pproduction -Dgpg.skip=true
   java -jar target/max-translator-bot.jar
   ```

使用的模型在 `app.properties` 中配置，默认是 `ai.platform=deepseek`、`ai.model=deepseek-flash`。

::: warning 默认使用本地代理
Telegram 请求和模型请求默认都经过 HTTP 代理 `127.0.0.1:10808`，启动前要确保代理可用。用 `telegram.http.proxy` 修改：值为 `host:port`，设为 `none` 时直连。部署文件 `fly.toml` 已设为 `none`。
:::

```java
    }
  }
```

## 建表

启动时用 `CREATE TABLE IF NOT EXISTS` 创建缓存表，`md5` 上的唯一键用于并发去重：

```java
package io.nexus.gpt.translator.config;

import nexus.io.db.activerecord.Db;
import nexus.io.tio.boot.admin.config.TioAdminDbConfiguration;

public class TranslatorDatabaseConfig {
  public void config() {
    new TioAdminDbConfiguration().config();
    Db.update("""
        CREATE TABLE IF NOT EXISTS max_kb_sentence_tanslate_cache (
          id BIGINT PRIMARY KEY,
          md5 VARCHAR(32) NOT NULL UNIQUE,
          "from" VARCHAR(32) NOT NULL,
          user_id VARCHAR(64),
          src_lang VARCHAR(32) NOT NULL,
          src_text TEXT NOT NULL,
          dst_lang VARCHAR(32) NOT NULL,
          dst_text TEXT NOT NULL,
          elapsed BIGINT NOT NULL,
          created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
        )
        """);
  }
}
```

## HTTP 客户端

Telegram 客户端、长轮询和模型调用共用一个 `OkHttpClient`，代理从 `telegram.http.proxy` 读取：

```java
package io.nexus.gpt.translator.config;

import java.net.InetSocketAddress;
import java.net.Proxy;
import java.util.concurrent.TimeUnit;

import nexus.io.tio.utils.environment.EnvUtils;
import okhttp3.OkHttpClient;

public class BotHttpClient {
  public static final String PROXY_KEY = "telegram.http.proxy";
  public static final String DEFAULT_PROXY = "127.0.0.1:10808";
  public static final String NO_PROXY = "none";

  public static final OkHttpClient CLIENT = new OkHttpClient.Builder()
      .proxy(parseProxy(EnvUtils.get(PROXY_KEY, DEFAULT_PROXY)))
      .connectTimeout(15, TimeUnit.SECONDS)
      .readTimeout(120, TimeUnit.SECONDS)
      .callTimeout(120, TimeUnit.SECONDS)
      .retryOnConnectionFailure(false)
      .build();

  /**
   * Parses host:port. "none" connects directly.
   */
  public static Proxy parseProxy(String value) {
    String proxy = value == null ? "" : value.strip();
    if (proxy.isEmpty() || NO_PROXY.equalsIgnoreCase(proxy)) {
      return Proxy.NO_PROXY;
    }
    int separator = proxy.lastIndexOf(':');
    if (separator <= 0 || separator == proxy.length() - 1) {
      throw new IllegalArgumentException(PROXY_KEY + " must be host:port or none: " + value);
    }
    int port;
    try {
      port = Integer.parseInt(proxy.substring(separator + 1));
    } catch (NumberFormatException error) {
      throw new IllegalArgumentException(PROXY_KEY + " must be host:port or none: " + value, error);
    }
    if (port < 1 || port > 65535) {
      throw new IllegalArgumentException(PROXY_KEY + " port is out of range: " + value);
    }
    return new Proxy(Proxy.Type.HTTP, InetSocketAddress.createUnresolved(proxy.substring(0, separator), port));
  }

  public static void close() {
    CLIENT.dispatcher().executorService().shutdown();
    CLIENT.connectionPool().evictAll();
  }
}
```

## 启动长轮询

`TelegramBotConfig` 负责：

1. 检查 `telegram.bot.token`。
2. 给 `TelegramClientCan.main` 赋值，并用 `getMe` 记下 `botId`。
3. 删除旧 WebHook，`dropPendingUpdates(false)` 保留待处理消息。
4. 注册消费者开始长轮询。
5. 用 `HookCan` 注册退出逻辑，顺序见[并发、限流与退出](./03.md#退出顺序)。

```java
package io.nexus.gpt.translator.config;

import com.fasterxml.jackson.databind.ObjectMapper;
import io.nexus.gpt.translator.consumer.TranslatorUpdateConsumer;
import io.nexus.telegram.can.RateLimiterManager;
import io.nexus.telegram.can.TelegramClientCan;
import nexus.io.hook.HookCan;
import nexus.io.jfinal.aop.Aop;
import nexus.io.tio.utils.environment.EnvUtils;
import org.telegram.telegrambots.client.okhttp.OkHttpTelegramClient;
import org.telegram.telegrambots.longpolling.TelegramBotsLongPollingApplication;
import org.telegram.telegrambots.meta.api.methods.updates.DeleteWebhook;
import org.telegram.telegrambots.meta.api.objects.User;
import org.telegram.telegrambots.meta.exceptions.TelegramApiException;
import org.telegram.telegrambots.meta.generics.TelegramClient;

import lombok.extern.slf4j.Slf4j;

@Slf4j
public class TelegramBotConfig {
  public void config() {
    String token = EnvUtils.getStr("telegram.bot.token");
    if (token == null || token.isBlank()) {
      throw new IllegalStateException("telegram.bot.token is required");
    }
    TelegramClient client = new OkHttpTelegramClient(BotHttpClient.CLIENT, token);
    TelegramClientCan.main = client;
    TranslatorUpdateConsumer consumer = Aop.get(TranslatorUpdateConsumer.class);
    TelegramBotsLongPollingApplication application = new TelegramBotsLongPollingApplication(
        ObjectMapper::new, () -> BotHttpClient.CLIENT);
    try {
      User bot = TelegramClientCan.getMe();
      TelegramClientCan.botId = bot.getId();
      client.execute(DeleteWebhook.builder().dropPendingUpdates(false).build());
      application.registerBot(token, consumer);
      log.info("Long polling started for @{} via {}", bot.getUserName(), BotHttpClient.CLIENT.proxy());
    } catch (TelegramApiException error) {
      consumer.close();
      try {
        application.close();
      } catch (Exception closeError) {
        error.addSuppressed(closeError);
      }
      throw new IllegalStateException("Telegram long polling initialization failed", error);
    }
    HookCan.me().addDestroyMethod(() -> {
      try {
        application.close();
      } catch (Exception error) {
        log.warn("Failed to close Telegram polling", error);
      }
      consumer.close();
      RateLimiterManager.shutdown();
      BotHttpClient.close();
    });
  }
}
```

## 处理消息

消费者跳过非文本和其他机器人的消息，先匹配命令，再翻译。只要文本中有汉字就判定为中文，否则判定为英文。

翻译失败时只回复一条提示，错误写入日志。回复按 3900 个字符分条（Telegram 单条上限是 4096），并避免拆开 Unicode 代理对。

```java
package io.nexus.gpt.translator.consumer;

import java.util.ArrayList;
import java.util.List;

import io.nexus.gpt.translator.services.TranslatorService;
import io.nexus.gpt.translator.vo.TranslatorTextVo;
import io.nexus.telegram.bot.command.EchoCommandFunction;
import io.nexus.telegram.bot.command.InfoCommandFunction;
import io.nexus.telegram.can.TelegramClientCan;
import io.nexus.telegram.utils.LongPollingMultiThreadUpdateConsumer;
import io.nexus.telegram.utils.SendMessageUtils;
import io.nexus.telegram.utils.TgUserUtils;
import nexus.io.jfinal.aop.Aop;
import org.telegram.telegrambots.meta.api.objects.Update;
import org.telegram.telegrambots.meta.api.objects.message.Message;

import lombok.extern.slf4j.Slf4j;

@Slf4j
public class TranslatorUpdateConsumer extends LongPollingMultiThreadUpdateConsumer {
  @Override
  public void consume(Update update) {
    if (!update.hasMessage() || !update.getMessage().hasText()) {
      return;
    }
    Message message = update.getMessage();
    if (message.getFrom() != null && Boolean.TRUE.equals(message.getFrom().getIsBot())) {
      return;
    }
    Long chatId = message.getChatId();
    if (hasCommand(message, "/start") || hasCommand(message, "/help")) {
      send(chatId, "发送中文翻译为英文，发送英文翻译为中文。支持 /echo 和 /info。");
      return;
    }
    if (hasCommand(message, "/echo")) {
      Aop.get(EchoCommandFunction.class).index(update);
      return;
    }
    if (hasCommand(message, "/info")) {
      Aop.get(InfoCommandFunction.class).index(update);
      return;
    }
    String text = message.getText();
    if (text.isBlank()) {
      return;
    }
    boolean chinese = text.codePoints().anyMatch(code -> Character.UnicodeScript.of(code) == Character.UnicodeScript.HAN);
    TranslatorTextVo input = new TranslatorTextVo(text, chinese ? "Chinese" : "English", chinese ? "English" : "Chinese");
    try {
      Long userId = TgUserUtils.getUserId(update);
      String answer = Aop.get(TranslatorService.class).translate(userId == null ? null : userId.toString(), input);
      send(chatId, answer);
      log.info("Translation delivered for update {}", update.getUpdateId());
    } catch (Exception error) {
      log.error("Translation failed for update {}", update.getUpdateId(), error);
      send(chatId, "翻译暂时失败，请稍后重试。");
    }
  }

  @Override
  public void consumeGroup(List<Update> updates) {
    for (Update update : updates) {
      consume(update);
    }
  }

  protected void send(Long chatId, String text) {
    for (String part : splitReply(text)) {
      TelegramClientCan.execute(SendMessageUtils.text(chatId, part));
    }
  }

  public static List<String> splitReply(String text) {
    List<String> parts = new ArrayList<>();
    for (int start = 0; start < text.length();) {
      int end = Math.min(start + 3900, text.length());
      if (end < text.length() && Character.isHighSurrogate(text.charAt(end - 1))) {
        end--;
      }
      parts.add(text.substring(start, end));
      start = end;
    }
    return parts;
  }
}
```

## 翻译与缓存

- **缓存键**：平台、模型、源语言、目标语言和原文一起计算 MD5，换模型不会命中旧翻译。
- **用户 ID**：保存实际发送者的 ID，不把群聊 ID 当作用户 ID。
- **并发写入**：`ON CONFLICT (md5) DO NOTHING` 处理相同翻译的并发写入。
- **长文本**：按 2000 token 递归对半切分，逐段翻译后拼接。

```java
package io.nexus.gpt.translator.services;

import java.io.IOException;
import java.util.ArrayList;
import java.util.List;

import io.nexus.gpt.translator.config.BotHttpClient;
import io.nexus.gpt.translator.vo.TranslatorTextVo;
import nexus.io.chat.UniChatClient;
import nexus.io.chat.UniChatMessage;
import nexus.io.chat.UniChatRequest;
import nexus.io.chat.UniChatResponse;
import nexus.io.consts.ModelPlatformName;
import nexus.io.db.activerecord.Db;
import nexus.io.db.activerecord.Row;
import nexus.io.deepseek.DeepSeekModels;
import nexus.io.tio.utils.crypto.Md5Utils;
import nexus.io.tio.utils.environment.EnvUtils;
import nexus.io.tio.utils.json.JsonUtils;
import nexus.io.tio.utils.snowflake.SnowflakeIdUtils;
import nexus.io.utils.TokenUtils;

public class TranslatorService {
  private static final int MAX_TOKENS_PER_REQUEST = 2000;

  public String translate(String userId, TranslatorTextVo input) {
    String key = cacheKey(input);
    Row row = Db.findFirst("select dst_text from max_kb_sentence_tanslate_cache where md5 = ?", key);
    if (row != null) {
      return row.getStr("dst_text");
    }
    long start = System.currentTimeMillis();
    String answer = translate(input);
    Db.update("""
        INSERT INTO max_kb_sentence_tanslate_cache
          (id, md5, "from", user_id, src_lang, src_text, dst_lang, dst_text, elapsed)
        VALUES (?, ?, 'telegram', ?, ?, ?, ?, ?, ?)
        ON CONFLICT (md5) DO NOTHING
        """, SnowflakeIdUtils.id(), key, userId, input.getSrcLang(), input.getSrcText(),
        input.getDestLang(), answer, System.currentTimeMillis() - start);
    return answer;
  }

  public String cacheKey(TranslatorTextVo input) {
    return Md5Utils.md5Hex(JsonUtils.toJson(List.of(
        EnvUtils.get("ai.platform", ModelPlatformName.DEEPSEEK),
        EnvUtils.get("ai.model", DeepSeekModels.deepseek_flash),
        input.getSrcLang(), input.getDestLang(), input.getSrcText())));
  }

  public String translate(TranslatorTextVo input) {
    if (input.getSrcText() == null || input.getSrcText().isBlank()) {
      throw new IllegalArgumentException("Source text must not be blank");
    }
    List<String> chunks = splitTextIntoChunks(input.getSrcText(), TokenUtils.countTokens(input.getSrcText()),
        MAX_TOKENS_PER_REQUEST);
    StringBuilder result = new StringBuilder();
    for (String chunk : chunks) {
      UniChatRequest request = new UniChatRequest(
          EnvUtils.get("ai.platform", ModelPlatformName.DEEPSEEK),
          EnvUtils.get("ai.model", DeepSeekModels.deepseek_flash));
      request.setSystemPrompt("Translate from " + input.getSrcLang() + " to " + input.getDestLang()
          + ". Preserve formatting. Return only the translation without explanations.")
          .setMessages(List.of(UniChatMessage.buildUser(chunk)))
          .setStream(false).setMax_tokens(4096);
      try {
        UniChatResponse response = UniChatClient.generate(BotHttpClient.CLIENT, request);
        String content = response.getMessage().getContent();
        if (content == null || content.isBlank()) {
          throw new IllegalStateException("Model returned an empty translation");
        }
        if (!result.isEmpty()) {
          result.append('\n');
        }
        result.append(content);
      } catch (IOException error) {
        throw new IllegalStateException("Translation request failed", error);
      }
    }
    return result.toString();
  }

  public List<String> splitTextIntoChunks(String text, int tokenCount, int maxTokens) {
    if (maxTokens < 1) {
      throw new IllegalArgumentException("maxTokens must be positive");
    }
    List<String> chunks = new ArrayList<>();
    split(text, maxTokens, chunks);
    return chunks;
  }

  private void split(String text, int maxTokens, List<String> chunks) {
    if (TokenUtils.countTokens(text) <= maxTokens) {
      chunks.add(text);
      return;
    }
    int count = text.codePointCount(0, text.length());
    if (count < 2) {
      throw new IllegalArgumentException("Token budget cannot hold one character");
    }
    int middle = text.offsetByCodePoints(0, count / 2);
    split(text.substring(0, middle), maxTokens, chunks);
    split(text.substring(middle), maxTokens, chunks);
  }
}
```

## 测试

默认测试不访问 Telegram、模型服务或数据库：

```bash
mvn test -Dgpg.skip=true
```

真实模型与数据库的集成测试需要显式开启，它检查缓存写入和重复命中，不向 Telegram 发消息：
