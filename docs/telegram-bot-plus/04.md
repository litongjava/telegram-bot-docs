# WebHook 模式

telegram-bot-plus 的测试和 max-translator-bot 都使用长轮询，长轮询不需要公网地址，建议优先使用。必须使用 WebHook 时，可以把更新交给同一个消费者，业务代码不用改。

::: warning 未经项目验证
本页的代码已编译通过，但 telegram-bot-plus 和 max-translator-bot 都没有 WebHook 模式的测试，使用前请自行验证。
:::

## 接收更新

`consume(List<Update>)` 是消费者的公开入口，在控制器中调用它，就能沿用同一聊天按顺序处理、媒体组聚合等逻辑：

```java
import java.util.List;

import org.telegram.telegrambots.meta.api.objects.Update;

import nexus.io.annotation.AController;
import nexus.io.annotation.RequestPath;
import nexus.io.jfinal.aop.Aop;
import nexus.io.tio.boot.http.TioRequestContext;
import nexus.io.tio.http.common.HttpRequest;
import nexus.io.tio.http.common.HttpResponse;
import nexus.io.tio.utils.json.JacksonUtils;

@AController
@RequestPath("/telegram")
public class TelegramWebhookController {

  @RequestPath("/webhook")
  public HttpResponse webhook(HttpRequest request) {
    Update update = JacksonUtils.parse(request.getBodyString(), Update.class);
    Aop.get(EchoConsumer.class).consume(List.of(update));
    return TioRequestContext.getResponse();
  }
}
```

这里的 `EchoConsumer` 是[快速开始](./01.md)里的消费者，换成你自己的即可。

## 设置地址

```java
import org.telegram.telegrambots.meta.api.methods.updates.SetWebhook;
import org.telegram.telegrambots.meta.exceptions.TelegramApiException;

import io.nexus.telegram.can.TelegramClientCan;

public class WebhookSetup {
  public static void register(String url) throws TelegramApiException {
    TelegramClientCan.main.execute(SetWebhook.builder().url(url).build());
  }
}
```

WebHook 地址必须是 HTTPS。切回长轮询前要删除 WebHook，可以参考翻译机器人启动时调用的 `DeleteWebhook`。
